# Foocus Marketing Site

Build a polished, production-ready marketing website / landing page for my app Foocus.

IMPORTANT: Before making changes, inspect the existing project structure and existing Foocus code/assets so you understand the app's branding and don't unnecessarily modify or break anything. This is a marketing website for the existing Foocus app, not a redesign of the actual mobile app.

BRAND / VISUAL DIRECTION

Foocus is an AI-powered productivity/task-management app.

The website should feel:

Modern

Calm

Intelligent

Premium

Friendly

AI-native

Clean and trustworthy

Light and soft rather than dark

Use the existing Foocus logo and branding assets I provide.

Use the Foocus logo as:

The main logo in the navbar

The footer logo

The favicon / browser tab icon

The appropriate social/share preview branding where possible

The overall visual language should use Foocus's blue + white aesthetic.

DO NOT use:

Purple gradients

Generic purple/blue AI gradients

Black/dark SaaS themes

Excessive glassmorphism

Every section looking like floating glass

Excessive rounded cards

Huge pill-shaped UI everywhere

Generic AI landing-page illustrations

Overly futuristic neon effects

Clutter

Excessive animations

The website should NOT look like a template.

Use a mostly white/light background with subtle blue-tinted sections, soft borders, restrained shadows, and tasteful blue accents.

SHAPE LANGUAGE

Avoid making everything rounded.

Use a mixture of:

Square / slightly rounded containers

Subtle corner radii

Clean rectangular sections

Thin borders

Occasional cards where they actually improve hierarchy

Buttons can have a modest radius, but don't turn every element into a pill.

The design should feel polished without relying on rounded corners or glassmorphism.

RESPONSIVENESS

Make the entire website fully responsive:

Desktop

Tablet

Mobile

The mobile layout should feel intentionally designed rather than simply stacking the desktop layout.

LANDING PAGE

Create a strong homepage for Foocus.

NAVBAR

Create a clean sticky or semi-sticky navbar.

Include:

Foocus logo

Product / Features

How it works

Pricing

FAQ

Privacy / Terms where appropriate

Primary CTA such as "Get Foocus"

Keep the navbar minimal.

On mobile, use a clean mobile navigation menu.

HERO SECTION

Create a strong hero section immediately communicating what Foocus does.

Suggested positioning:

"Focus on what matters."

Foocus is an AI-powered productivity app that helps you organize tasks, stay focused, and get more done with less friction.

Use concise copy rather than a huge wall of text.

Include two CTAs:

Primary: "Get Foocus"

Secondary: "See how it works"

Use the actual Foocus app screenshot I provide as the main visual if appropriate.

Do NOT create a generic AI robot illustration.

The hero should make the product feel real.

Add subtle, tasteful visual details such as:

Soft blue background shapes

Very subtle grid/noise

Small UI accents

Gentle motion

But keep it restrained.

SOCIAL PROOF / TRUST

Add a lightweight trust section below the hero.

Don't invent fake customer numbers, reviews, company logos, awards, or statistics.

If real information is not available, use a simple statement such as:

"Designed to make everyday productivity feel simpler."

FEATURES

Create a polished feature section explaining the core Foocus experience.

Focus on the actual product capabilities rather than generic AI claims.

Possible feature areas:

AI-powered productivity

Foocus helps turn your intentions into actionable tasks and helps you stay organized.

Smart task management

Create, organize, prioritize, and complete tasks without unnecessary complexity.

Focus experience

Help users stay focused on what matters instead of constantly managing their productivity system.

Intelligent assistance

Use AI to make planning and managing tasks easier.

Only claim functionality that actually exists in the current Foocus app. Inspect the existing code/project and use the real features where possible.

Use a visually interesting layout rather than a repetitive grid of identical cards.

PRODUCT SHOWCASE

Create a section that visually showcases Foocus.

Use the provided Foocus app screenshot(s) if available.

Show the product in a realistic device/browser presentation.

Do not distort screenshots.

This section should communicate:
"This is a real product you can use."

HOW IT WORKS

For example:

01 — Add what you need to get done
02 — Let Foocus help organize your work
03 — Stay focused and get it done

Keep it visually clean.

The messaging should make AI feel useful rather than gimmicky.

Possible headline:

"Less managing. More doing."

Explain that Foocus uses AI to reduce the friction involved in planning and organizing tasks.

Use subtle blue visual accents.

PRICING

Create a clean pricing section.

IMPORTANT:

Do NOT invent pricing.

If the current project contains monthly/yearly plans, display them accurately.

Clearly distinguish:

Free

Pro / Premium

Include a clear CTA for upgrading.

Do not make the pricing cards overly rounded or glassy.

Is Foocus free?

What does Foocus Pro include?

Can I cancel my subscription?

Only make claims that are supported by the existing project/product.

Use an accordion.

FINAL CTA

Create a strong final CTA before the footer.

Example:

"Ready to focus?"

"Make your tasks simpler and your day more focused with Foocus."

CTA:
"Get Foocus"

Keep it clean and blue/white rather than using a giant gradient.

Inspect the existing Foocus implementation to determine what services are actually used and what data is collected.

If information is genuinely unknown, structure the page cleanly and use clearly marked placeholders that I can replace rather than silently inventing facts.

Make the Privacy Policy and Terms pages easily accessible from the footer.

Inspect the existing project before implementing.

Reuse the existing tech stack where possible.

Do not create fake product features.

Use Foocus blue + white branding.

Don't make every element rounded.

Use the actual Foocus logo I provide.
